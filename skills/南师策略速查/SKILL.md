# 南师策略速查

## When
User asks how a named 南师／南山 strategy works, or wants steps/parameters for VA, FGI, 老奶奶, 动量, MACD divergence, Vegas, 现货定投／分批／均线, 翻倍出本, MVRV逃顶, etc.

## Steps
1. Open the local strategy cheat sheet if present (`核心策略速查.md` or equivalent under `nanshi-materials`). Cross-check the matching Notion／PDF extract only when the cheat sheet is thin or the user asks for sources.
2. Identify which strategy (or closest match). If ambiguous, ask one clarifying question before dumping multiple systems.
3. Reply in this shape:
   - **核心**：one sentence mechanism
   - **条件／标的**：when it applies
   - **步骤**：ordered checklist
   - **原文参数**：only numbers from sources (FGI thresholds, MA lengths, share counts, etc.)
   - **缺口**：tables/charts/PDFs not extracted—say so, do not invent
   - **仓位提示**：主力 vs 小仓 (e.g. momentum/Vegas often small-sleeve)
4. Remind: one positive-expectation system + mechanical execution beats stacking indicators; KISS.
5. Historical backtest figures from notes are illustrations, never promises. Add a brief non-advice line.

## Do not
- Mix strategies into a new hybrid without labeling it as your synthesis vs source text.
- Change source thresholds (e.g. invent FGI=30).
- Present fund codes or old portfolio weights as current recommendations.
