# 大饼 120SMA±1.2% 日检

自用施密特（滞后）版：吃鱼身、减震荡假信号。与南师原文「收盘站上持币、跌破换稳」同方向，但加了 ±1.2% 带；**不要当成南师原文参数**。

## When

User asks for BTC／大饼相对 120 日 SMA 的仓位信号、±1.2% 缓冲带日检、持币／持 U 该维持还是切换，或要一份可定时推送的日报文案。

## 规则（钉死执行）

- 标的：BTC／USDT 日线
- 均线：120 日 **SMA**（简单均线，不是 EMA）
- **判定用最近一根已收盘日线收盘价**；现价只作旁注，不得单独用来触发切换
- 上沿（买入确认）= SMA × 1.012
- 下沿（卖出确认）= SMA × 0.988
- 持有 **BTC** 时：仅当收盘价 **<** 下沿 → 切换至 USDT；否则维持 BTC
- 持有 **USDT** 时：仅当收盘价 **>** 上沿 → 切换至 BTC；否则观望／维持 U
- 中间带：两边都不切换

## Steps

1. 取数据源（如币安 BTCUSDT）与时间（用户时区）
2. 算：最近日收、现价（旁注）、SMA120、上沿、下沿
3. 对比三项并写清：
   - 收盘 vs SMA（%）
   - 收盘 vs 上沿（差额与 %；是否站稳）
   - 收盘 vs 下沿（差额与 %；再跌约多少 % 才触及卖出线）
4. 标明区间：上方／中间带／下方
5. 分别给信号（只说维持或切换，不预测涨跌）：
   - 若当前持币：…
   - 若当前持 U：…（中间带必须写「观望／维持 U」，禁止「可切换至 BTC」）
6. 贴线但未触发时，可加一句「准备观察下沿／上沿，未确认穿越不动作」；**未跌破不下车，未站稳不上车**
7. 一两句提醒：机械执行、防假信号；不构成投资建议

```
【大饼 120SMA±1.2%｜日检】
{时区与日期}｜{数据源}｜判定：已收盘日线

- 最近日收 **{close}**
- 现价约 **{spot}**（旁注）
- 120 日 SMA **{sma}**
- 上沿（买入确认）SMA×1.012：**{upper}**
- 下沿（卖出确认）SMA×0.988：**{lower}**

**对比**
- 收盘 vs SMA：**{pct_sma}**
- 收盘 vs 上沿：**{pct_upper}**（…）
- 收盘 vs 下沿：**{pct_lower}**（再跌约 **{drop_to_sell}** 才触及 −1.2% 卖出线）
- 区间：**{zone}**

**信号**
- 若当前 **持币**：…
- 若当前 **持 U**：…

机械执行，防震荡假信号。不构成投资建议。
```

## Do not

- 用盘中现价略穿上沿就写「持 U 可切 BTC」
- 中间带写成准备买入或准备卖出（只能「维持／观望 + 盯线」）
- 把 ±1.2% 说成南师原文；原文无此缓冲
- 把「市场上涨幅常在约 1.2% 的时间里发生」那句金句，和本均线缓冲带混为一谈
- 承诺收益或给出个性化下单指令
